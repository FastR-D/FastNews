Callee: Recovering Call Graphs for Binaries with Transfer and Contrastive Learning

Wenyu Zhu ( Tsinghua University & BNRist, China ), Zhiyao Feng ( Tsinghua University & BNRist, China ), Zihan Zhang ( Tsinghua University & BNRist, China ), Jianjun Chen ( Tsinghua University & Zhongguancun Laboratory, China ), Zhijian Ou ( Tsinghua University, China ), Min Yang ( Fudan University, China ), Chao Zhang ( Tsinghua University & BNRist & Zhongguancun Laboratory, China )

核心总结

恢复二进制程序的调用图对过程间分析至关重要，核心挑战是识别间接调用目标，现有方案假阳性和假阴性高。本文提出Callee，结合迁移学习和对比学习，利用深度神经网络自动识别间接调用模式，通过对比学习回答调用点-被调函数问题，并用迁移学习在易收集的直接调用上预训练，再微调间接调用。在多个目标组上评估，Callee以94.6%的F1-Measure匹配调用点和被调函数，远优于现有方案；应用于二进制代码相似性检测和混合模糊测试，显著提升性能。

XFL: Naming Functions in Binaries with Extreme Multi-label Learning

James Patrick-Evans ( Royal Holloway, University of London ), Moritz Dannehl ( Bundeswehr University Munich ), Johannes Kinder ( Bundeswehr University Munich )

核心总结

逆向工程中函数名等标识符对分析很有价值，但二进制发布时通常被移除；自动预测函数名虽有前景，却因大多数函数名只出现一次而比自然语言词预测更困难。本文提出 XFL，一种极端多标签学习方法来为二进制函数选择合适标签：它将函数名拆分为 token，把每个 token 视为信息标签，并通过 Dexter 函数嵌入关联二进制代码语义。Dexter 结合静态分析特征、调用图局部上下文和整个二进制的全局上下文。在来自 Debian 项目的 10,047 个二进制数据集上，XFL/Dexter 达到 83.5% 精确率，优于现有函数标注方法；与其他二进制嵌入组合比较也表明 Dexter 始终最佳。

D-ARM: Disassembling ARM Binaries by Lightweight Superset Instruction Interpretation and Graph Modeling

Yapeng Ye ( Purdue University, USA ), Zhuo Zhang ( Purdue University, USA ), Qingkai Shi ( Purdue University, USA ), Yousra Aafer ( University of Waterloo, Canada ), Xiangyu Zhang ( Purdue University, USA )

核心总结

ARM 二进制分析在 ARM 系统安全中有广泛应用，但 ARM 反汇编尤其是 AArch32 面临 ARM/Thumb 指令模式混合、应用内隐式模式切换和内联数据普遍等独特挑战，现有技术在复杂混淆二进制上准确率不足。本文提出 D-ARM，一种专为 32 位 ARM 遗留代码设计的反汇编技术：它使用轻量级超集指令解释方法获取丰富语义信息，并用基于图论的方法聚合信息产生最终反汇编结果。作者在由 SPEC2000/SPEC2006 多种设置生成的数千个二进制以及在线收集的真实应用上，与 Ghidra、IDA、P-Disasm、XDA、D-Disasm 和 Spedi 等先进反汇编器比较。结果表明 D-ARM 大幅优于这些基线。

QueryX: Symbolic Query on Decompiled Code for Finding Bugs in COTS Binaries

HyungSeok Han ( Theori Inc., KAIST ), JeongOh Kyea ( Theori Inc. ), Yonghwi Jin ( Theori Inc. ), Jinoh Kang ( Theori Inc. ), Brian Pak ( Theori Inc. ), Insu Yun ( KAIST )

核心总结

源码静态检查工具如 Sys 和 CodeQL 可让分析人员编写查询发现漏洞，但多数无法用于二进制分析；现有二进制平台又要求理解中间表示，或对反编译代码的符号分析精度不足。QueryX 提出面向反编译代码的精确且可扩展符号分析框架，允许分析人员直接在反编译代码上编写直观查询，并通过回调控制符号分析。它把反编译代码提升为内部 IR（DNR）进行符号分析，同时利用回调和排序依赖自动削减控制流图以提升可扩展性。应用于 Windows 内核、Windows 系统服务和汽车二进制后，发现 15 个独特漏洞，包括 10 个 CVE，并获得 18 万美元漏洞赏金。

PyFET: Forensically Equivalent Transformation for Python Binary Decompilation

Ali Ahad ( University of Virginia, USA ), Chijung Jung ( University of Virginia, USA ), Ammar Askar ( Georgia Institute of Technology, USA ), Doowon Kim ( University of Tennessee, USA ), Taesoo Kim ( Georgia Institute of Technology, USA ), Yonghwi Kwon ( University of Virginia, USA )

核心总结

随着 Python 恶意软件增多，Python 反编译器成为取证分析的重要手段，但许多二进制会导致反编译错误，限制分析能力。PyFET 提出将导致反编译错误的 Python 二进制转换为可反编译二进制的新方案，核心是取证等价变换（FET），允许在取证分析场景下进行非语义保持变换，以修复难以在保持精确语义时处理的错误指令，并应对 opcode 重映射等反分析技术。作者在五个流行反编译器上评估了 17,117 个真实 Python 恶意软件样本。结果成功识别并修复 77,022 个错误，还能帮助将 Python 3.9 二进制迁移到 3.8 二进制。

SoK: Distributed Randomness Beacons

Kevin Choi ( New York University, USA ), Aathira Manoj ( New York University, USA ), Joseph Bonneau ( New York University, USA and a16z crypto research, USA )

核心总结

受区块链推动，许多分布式可验证随机性协议被提出，它们在不同设置和假设下使用多种密码工具，各有取舍。本文系统化梳理分布式随机性信标（DRB）的设计及其依赖的密码构件。围绕不可偏置性和不可预测性两个关键安全属性评估协议，讨论预测或偏置信标输出的常见攻击向量及对策，并比较通信与计算效率。最后给出不同部署场景下的适用性见解及未来研究方向。

WeRLman: To Tackle Whale (Transactions), Go Deep (RL)

Roi Bar-Zur ( Technion, IC3 ), Ameer Abu-Hanna ( Technion ), Ittay Eyal ( Technion, IC3 ), Aviv Tamar ( Technion )

核心总结

PoW区块链安全依赖激励，若矿工算力超过阈值可能通过自私挖矿获利；但以往分析假设奖励恒定，而实际存在偶尔的“鲸鱼”区块（异常高奖励）。对这种行为建模会导致状态空间随参数指数增长，现有分析工具难以处理。本文提出WeRLman框架，受AlphaGo Zero启发使用深度强化学习，并针对随机模型引入方差缩减技术利用系统循环性和转移概率先验知识。评估表明其在区块链深度RL分析中达到前所未有精度。分析发现费用波动性与安全阈值负相关：比特币历史费用下阈值未来10/20/30年降至0.2/0.17/0.12，以太坊近期费用下降至0.17，低于大型矿工常见规模。

Bitcoin-Enhanced Proof-of-Stake Security: Possibilities and Impossibilities

Ertem Nusret Tas ( Stanford University ), David Tse ( Stanford University ), Fangyu Gai ( BabylonChain Inc. ), Sreeram Kannan ( University of Washington, Seattle ), Mohammad Ali Maddah-Ali ( University of Minnesota ), Fisher Yu ( BabylonChain Inc. )

核心总结

比特币是最安全的区块链，PoS链节能且快速最终确定，但存在非罚没长程安全攻击、低活性韧性和低代币估值启动难等安全问题。本文证明这些安全问题在没有外部可信源的任何PoS链中固有，并提出Babylon协议，让现成PoS协议将检查点锚定到比特币以解决这些问题。不可能性结果证明Babylon最优性。用例是减少质押提现延迟：实验表明可将现有PoS链数周延迟降至不到5小时，每年向比特币发布检查点交易成本低于1万美元。

MEGA: Malleable Encryption Goes Awry

Matilda Backendal ( ETH Zurich ), Haller Miro ( ETH Zurich ), Kenneth G. Paterson ( ETH Zurich )

核心总结

MEGA是拥有超2.5亿用户、1000PB存储的云存储平台，声称提供用户控制的端到端安全，所有加解密在客户端进行以抵御MEGA或基础设施攻击者。本文在恶意服务器设置下详细分析MEGA的密码学使用，提出五种不同攻击，可完全破坏用户文件机密性。此外可破坏数据完整性，使攻击者插入通过客户端真实性检查的恶意文件。所有攻击均构建概念验证，其中四种非常实用，已负责任披露给MEGA并正在修复。作者给出可立即部署的对策和长期建议，并讨论大规模强威胁模型下密码部署挑战。

Practically-exploitable Cryptographic Vulnerabilities in Matrix

Martin R. Albrecht ( King’s College London ), Sofía Celi ( Brave Software ), Benjamin Dowling ( Security of Advanced Systems Group, University of Sheffield ), Daniel Jones ( Information Security Group, Royal Holloway, University of London )

核心总结

Matrix是联邦实时通信标准，其旗舰客户端Element使用多种知名密码构件，但本文报告多个实际可利用的密码漏洞。这些漏洞包括设计不安全、协议混淆、缺乏域分离和实现缺陷，分布在其密码核心的不同子协议和库中。它们共同使Matrix声称的针对恶意服务器的机密性和认证保证失效。作者强调需要对Matrix标准中的密码学进行系统和形式化分析。

DBREACH: Stealing from Databases Using Compression Side-Channels

Mathew Hogan ( Stanford University ), Yan Michalevsky ( Anjuna Security, Inc and Cryptosat, Inc. ), Saba Eskandarian ( UNC Chapel Hill )

核心总结

本文提出针对同时支持数据库页压缩和静态加密的数据库存储引擎的新型压缩侧信道攻击。仅通过磁盘文件大小获得的近似密文大小信息（而非TLS场景中精确长度），攻击者就能高精度提取任意明文。攻击克服数据库环境独特障碍，结合噪声放大和针对数据库的新启发式。在MariaDB/MySQL的InnoDB和MongoDB的WiredTiger上，可检测随机字符串是否出现在表中（>90%准确率），并从加密表提取10字符随机字符串（>95%成功率）。

Weak Fiat-Shamir Attacks on Modern Proof Systems

Quang Dao ( Carnegie Mellon University ), Jim Miller ( Trail of Bits ), Opal Wright ( Trail of Bits ), Paul Grubbs ( University of Michigan )

核心总结

现代证明系统广泛使用Fiat-Shamir变换去除交互，但错误使用“弱”F-S可能导致经典协议被攻破，其对现代证明系统的风险尚不明确。本文对现代证明系统实现中的F-S进行广泛理论与实践研究，调查开源实现发现30个弱F-S实现影响12种证明系统。针对Bulletproofs、Plonk、Spartan和Wesolowski VDF四种，提出新的知识可靠性攻击并给出严格证明。案例研究表明弱F-S漏洞可在私有智能合约平台中导致无限制创建货币，最后讨论缓解措施和启示。

Public Verification for Private Hash Matching

Sarah Scheffler ( Princeton University ), Anunay Kulshrestha ( Princeton University ), Jonathan Mayer ( Princeton University )

核心总结

端到端加密阻碍了服务端对儿童性虐待材料（CSAM）进行明文感知哈希匹配，私有哈希匹配（PHM）允许在不暴露哈希集和非匹配内容的情况下进行检测，但引发安全、隐私和言论自由争议。本文提出新的密码学方法，使公众可对PHM系统进行验证，将批评系统化为对哈希集信任和实现信任两类。核心贡献是设计三类公开验证协议：外部团体批准哈希集的证明、特定合法内容不在哈希集中的证明、以及误报最终通知用户。协议实用高效，且兼容现有PHM构造，可部分缓解PHM部署中的信任问题。

Flamingo: Multi-Round Single-Server Secure Aggregation with Applications to Private Federated Learning

Yiping Ma ( University of Pennsylvania ), Jess Woods ( University of Pennsylvania ), Sebastian Angel ( University of Pennsylvania, Microsoft Research ), Antigoni Polychroniadou ( JP Morgan AI Research ), Tal Rabin ( University of Pennsylvania )

核心总结

该论文提出 Flamingo，用于在大量客户端之间安全聚合数据，服务器只能获得客户端私有输入之和，无法获知超出总和的信息。现有协议多针对单轮设计，需在联邦学习多轮训练中反复执行，带来每轮初始化和交互开销。Flamingo 消除了每轮设置需求，引入轻量级掉线恢复协议，并采用新的客户端邻域选择方式，减少客户端与服务器交互。实验表明，它能在 (Extended) MNIST 和 CIFAR-100 上安全训练神经网络，模型收敛且精度相比非隐私联邦学习没有损失。

SoK: Cryptographic Neural-Network Computation

Lucien K. L ( Georgia Institute of Technology ), Sherman S. M. Chow ( Chinese University of Hong Kong )

核心总结

该文系统梳理了 2016 至 2022 年间 53 篇基于密码学的隐私保护神经网络论文，这些工作不依赖可信处理器或差分隐私。作者按技术路线将工作分为仅用同态加密、用于推理的安全计算、以及非串谋服务器（其中 12 篇支持训练）等类别，并剖析其密码技术与机器学习之间的复杂关系。文章还绘制了发展谱系，并在广域网环境下重新评估现有方案性能，为跨领域研究者提供指南。

FLUTE: Fast and Secure Lookup Table Evaluations

Andreas Brüggemann ( Technical University of Darmstadt ), Robin Hundt ( Technical University of Darmstadt ), Thomas Schneider ( Technical University of Darmstadt ), Ajith Suresh ( Technical University of Darmstadt ), Hossein Yalame ( Technical University of Darmstadt )

核心总结

安全多方计算中，用查找表（LUT）替代布尔电路可得到更紧凑的电路，并在安全浮点运算和隐私保护机器学习推理中显著改善在线性能，但现有 LUT 协议要么预处理开销大，要么在线性能不佳。该文提出 FLUTE，一种兼顾预处理与在线性能的安全 LUT 评估协议。在两方场景下，FLUTE 的在线性能匹配或超过所有先前方法，整体性能也与最佳 LUT 协议相当。作者还提供 Rust 开源实现，并集成 ABY2.0 与 silent OT，实验显示在线阶段比现有最优方案快约两个数量级，同时通信量相当。

Bicoptor: Two-round Secure Three-party Non-linear Computation without Preprocessing for Privacy-preserving Machine Learning

Lijing Zhou ( Huawei Technology, China ), Ziyu Wang ( Huawei Technology, China ), Hongrui Cui ( Shanghai Jiao Tong University, China ), Qingrui Song ( Huawei Technology, China ), Yu Yu ( Shanghai Jiao Tong University, China )

核心总结

隐私保护机器学习的性能瓶颈常来自非线性函数的安全计算。该文提出 Bicoptor 系列三方安全计算协议，通过巧妙复用 SecureML 中的截断协议，设计出仅需两轮通信且无需预处理的符号判定协议。基于该协议，作者为 ReLU、Maxpool 及其变体等非线性函数构建了适合 GPU 加速的协议族。实验在公有云三方局域网中实现每秒超过 37 万次 DReLU/ReLU 或 4.1 万次 Maxpool 运算，ReLU 性能比 Falcon 和 Edabits 等最优工作提升一至两个数量级。

Threshold BBS+ Signatures for Distributed Anonymous Credential Issuance

Jack Doerner ( Technion ), Yashvanth Kondi ( Aarhus University ), Eysa Lee ( Northeastern University ), abhi shelat ( Northeastern University ), LaKyah Tyner ( Northeastern University )

核心总结

论文研究 BBS+ 签名方案的安全多方签名协议，用于实现阈值签发的匿名凭证。由于 BBS+ 签名的特殊结构，作者证明只需验证半诚实协议产生的签名即可实现针对恶意敌手的可组合安全性。因此协议非常简单高效：客户端向签名方发出一次请求，签名方之间进行两轮消息交换，最后向客户端返回响应；某些部署场景下瓶颈可能是客户端本地验证签名。该协议还可扩展支持最强形式的盲签名，并可作为 Dodis-Yampolskiy Oblivious VRF 的分布式评估协议，作者通过实现和基准测试验证了效率。

Private Access Control for Function Secret Sharing

Sacha Servan-Schreiber ( MIT CSAIL ), Simon Beyzerov ( MIT PRIMES ), Eli Yablon ( MIT PRIMES ), Hyojae Park ( MIT PRIMES )

核心总结

Function Secret Sharing 允许 dealer 将函数 f 分发给多个 evaluator，evaluator 可本地计算 f(x) 的秘密份额且不泄露 f。论文首次研究 FSS 的访问控制：给定 f 的份额，evaluator 应能验证 dealer 是否拥有该函数的访问密钥，从而判断其是否有权分享该函数。作者给出定义和构造，核心构件是秘密共享元素上的离散对数零知识知识证明，该构件本身也可能有独立价值。评估显示，在匿名通信中相比现有访问控制技术计算开销降低 50 至 70 倍；在私有数据库等应用中，引入访问控制的处理成本仅为 1.5 至 3 倍，且可被 50 万条以上数据摊销。

MPCAuth: Multi-factor Authentication for Distributed-trust Systems

Sijun Tan ( UC Berkeley ), Weikeng Chen ( UC Berkeley ), Ryan Deng ( UC Berkeley ), Raluca Ada Popa ( UC Berkeley )

核心总结

分布式信任系统将关键秘密分散在 N 台服务器上，并使用安全多方计算进行操作，但其认证面临易用性和隐私两大挑战：客户端若分别向每台服务器认证每种因子，需要 N 次认证；同时客户端敏感 profile 会暴露给所有服务器，扩大攻击面。论文提出 MPCAuth，使客户端只需一次认证工作量即可向 N 台服务器独立认证，并实现 profile hiding，即除非所有服务器都被攻陷，邮箱用户名、电话号码、密码和生物特征才不会泄露。作者为邮件验证码、短信、U2F、安全问题/密码和生物特征等常见认证因子设计了安全实用的协议。该系统适用于加密货币托管和协作机器学习等分布式信任场景。

Silph: A Framework for Scalable and Accurate Generation of Hybrid MPC Protocols

Edward Chen ( Carnegie Mellon University; Stanford University ), Jinhao Zhu ( Carnegie Mellon University ), Alex Ozdemir ( Stanford Univesity ), Riad Wahby ( Carnegie Mellon University ), Fraser Brown ( Carnegie Mellon University ), Wenting Zheng ( Carnegie Mellon University )

核心总结

金融和医疗等应用常需跨组织联合计算，但因监管约束和商业竞争无法明文共享数据，安全多方计算是可行方案，但其性能优化对缺乏高级密码学经验的用户而言门槛很高。论文提出 Silph，可将高层语言编写的程序自动编译为优化且安全的混合 MPC 协议，安全高效地混合多种 MPC 原语。相比先前工作，Silph 的编译速度最多提升 30000 倍；在多种数据库分析和机器学习负载上，其生成的 MPC 协议性能匹配或超过先前工作最多 3.6 倍。该工作降低了非密码专家使用 MPC 的难度。

Sound Verification of Security Protocols: From Design to Interoperable Implementations

Linard Arquint ( ETH Zurich, Switzerland ), Felix A. Wolf ( ETH Zurich, Switzerland ), Joseph Lallemand ( Univ Rennes, CNRS, IRISA, France ), Ralf Sasse ( ETH Zurich, Switzerland ), Christoph Sprenger ( ETH Zurich, Switzerland ), Sven N. 该论文针对 Web 应用攻击调查中现有方法分析粗糙、高并发场景性能差、依赖大量人工分析的问题，提出 TeSec 服务器端攻击调查方法。TeSec 利用两类关联：一是基于按 PID/TID 划分并带有分隔日志的审计日志，建立审计日志条目与 Web 请求之间的对应关系；二是通过在系统测试阶段构建 Aho-Corasick 自动机，建立请求与 UI 元素/事件之间的对应关系。基于这两类关联，TeSec 能在高并发场景下自动、准确地将告警定位到触发它的 UI 元素/事件，且仅需部署在服务器端，无需收集浏览器客户端日志。在 12 个 Web 应用上的实验表明，UI 事件/元素与告警的匹配准确率超过 99.6%，每次取证分析平均只需检查不超过 2 个 UI 元素，平均响应时间开销为 4.3%，审计日志空间开销为 4.6%。

Profile-guided System Optimizations for Accelerated Greybox Fuzzing

Yunhang Zhang, Chengbin Pang, Stefan Nagy, Xun Chen, Jun Xu

核心总结

灰盒模糊测试是安全测试的主流方法，已有大量算法改进，但系统级设计对模糊测试吞吐量的重要影响尚未得到充分关注。论文提出基于性能剖析（profile-guided）的系统优化方法，针对灰盒模糊测试工具的系统级瓶颈进行优化，以加速测试执行。该工作通过系统级剖析与优化提升模糊测试吞吐量，有望提高漏洞发现效率。

TypeSqueezer: When Static Recovery of Function Signatures for Binary Executables Meets Dynamic Analysis

Ziyi Lin, Jinku Li, Bowen Li, Haoyu Ma, Debin Gao, Jianfeng Ma

核心总结

控制流完整性是抵御高级代码复用攻击的有效方案，但后向边保护已较成熟，前向边保护仍是重大挑战，其核心是解析间接调用目标。在二进制层面，COTS 程序缺少实际类型信息，基于类型的间接调用目标匹配只能依赖由调用点和目标的数量及参数宽度近似推断的函数签名，静态分析往往被迫采用过度宽松的边界，难以防御复杂攻击。论文提出 TypeSqueezer，将二进制可执行文件函数签名的静态恢复与动态分析结合，以更精确地恢复函数签名并增强前向边 CFI 保护。

PackGenome: Automatically Generating Robust YARA Rules for Accurate Malware Packer Detection

Shijia Li, Jiang Ming, Pengda Qiu, Qiyuan Chen, Lanqing Liu, Huaifeng Bao, Qiang Wang, Chunfu Jia

核心总结

二进制打包是一种广泛使用的程序混淆技术，打包的恶意软件样本普遍存在，它们隐藏代码特征以逃避检测。安全分析师通过搜索特定二进制模式来识别打包器，但现有的人工编写规则（如YARA）严重依赖经验且误报率高。本文提出了PackGenome，自动生成鲁棒的YARA规则以准确检测恶意软件打包器。方法可能涉及分析打包器的行为特征来生成规则。评估表明，PackGenome生成的规则在检测准确率和误报率方面优于人工规则。

FITS: Matching Camera Fingerprints Subject to Software Noise Pollution

Liu Liu, Xinwen Fu, Xiaodong Chen, Jianpeng Wang, Zhongjie Ba, Feng Lin, Li Lu, Kui Ren

核心总结

相机 PRNU 指纹可用于设备认证，但图像后处理软件会引入额外噪声并残留在提取的 PRNU 指纹中，传统去噪难以消除；本文将其定义为软件噪声，会干扰设备认证。为此，作者提出 FITS 指纹匹配方法，先用 PCE 等统计量计算不同相机 PRNU 指纹间互相关以估计软件噪声相关性，再用目标 PRNU 指纹的统计量与估计软件噪声相关性之比来检测真实硬件噪声相关成分。基于 90 多部手机拍摄的 10,000 多张图像进行实验，结果表明 FITS 在受污染指纹匹配上显著优于现有方法。这是首个研究存在软件噪声时指纹匹配的工作。

Simplifying Mixed Boolean-Arithmetic Obfuscation by Program Synthesis and Term Rewriting

Jaehyung Lee, Woosuk Lee

核心总结

混合布尔算术（MBA）混淆可把表达式改写成复杂等价形式，既用于软件保护，也被恶意软件用于逃避检测，因此需要有效的MBA去混淆方法。现有MBA去混淆存在通用性、灵活性、可扩展性和正确性不足等问题。该论文提出ProMBA，将程序合成、项重写与代数化简协同结合，并在运行时学习去混淆变换规则。作者在超过4000个由先进混淆工具生成的MBA表达式上评估，结果显示其显著优于现有方法，能将绝大多数混淆表达式化简回原始形式。

Improving Security Tasks Using Compiler Provenance Information Recovered At the Binary-Level

Yufei Du, Omar Alrawi, Kevin Snow, Manos Antonakakis, Fabian Monrose

核心总结

现代编译器优化使二进制级编译器溯源成为可能，可识别编译器家族、优化级别甚至函数级 pass，但下游安全应用尚未充分挖掘。本文基于超过27000个 LLVM 14 构建程序，训练并评估多标签编译器溯源模型，覆盖68种编译器 pass，平均 F1 达84.4%。利用该模型，作者在10个流行项目中发现53个信息泄露 bug，并发现若干优化 pass 引入大量可被复用的功能代码 gadget，带来安全风险。该溯源信息还被用于验证 Windows 二进制 Rich header 正确性以及二进制分解和第三方库检测等任务。

CryptoBap: A Binary Analysis Platform for Cryptographic Protocols

Faezeh Nasrabadi, Robert Künnemann, Hamed Nemati

核心总结

验证密码协议实现的机器码安全具有挑战，因为需要从二进制中恢复协议模型并进行自动化验证。本文提出 CryptoBap，一个面向密码协议（ARMv8 和 RISC-V）机器码的弱保密性和认证性验证平台。它将协议二进制转译为中间表示，执行密码感知的符号执行以自动提取代表所有执行路径的协议模型，并可处理间接跳转和通过循环摘要技术支持有界循环。提取的模型经第三方工具链转换为 ProVerif 和 CryptoVerif 可验证模型；作者证明方法可靠性，并在 TinySSH 和 WireGuard 等真实协议案例上完成验证。

Scalable Multiparty Garbling

Gabrielle Beck, Aarushi Goel, Aditya Hegde, Abhishek Jain, Zhengzhong Jin, Gabriel Kaptchuk

核心总结

多方 garbling 是常量轮安全多方计算（MPC）的主流方案，但既往实例化方法难以支持大量参与方，通信开销随参与方数量增长而不可扩展。本文提出首个全局规模的多方 garbling 协议，其单方通信复杂度随参与方数量增加而下降，首次匹配非常量轮 MPC 协议的渐近通信复杂度。该协议在诚实多数设置下实现恶意安全，安全性依赖 Learning Parity with Noise（LPN）假设。

A Systematic Evaluation of Automated Tools for Side-Channel Vulnerabilities Detection in Cryptographic Libraries

Antoine Geimer, Mathéo Vergnolle, Frédéric Recoules, Lesly-Ann Daniel, Sébastien Bardin, Clémentine Maurice

核心总结

为保护密码实现免受侧信道漏洞影响，开发者必须采用常量时间编程实践，但这类实践容易出错，因此已有许多侧信道检测工具被提出。尽管如此，密码库中此类漏洞仍常被人工发现；Jancar 等人近期工作表明开发者很少执行侧信道检测，但尚不清楚现有检测工具是否本可发现这些漏洞。本文对密码库中侧信道漏洞检测的自动化工具进行系统性评估。通过评估工具能力与局限，论文分析其能否发现真实库中的漏洞，并为工具改进和开发者使用提供指导。

Towards Practical Sleepy BFT

Dahlia Malkhi, Atsuki Momose, Ling Ren

核心总结

比特币的最长链协议首次实现了动态参与下的共识（sleepy consensus），允许节点不必一直在线，但现有 sleepy 共识仍存在两个主要问题：延迟高，以及因无成本模拟问题而必须假设腐败节点集合固定。本文提出新的 sleepy BFT 协议，在最佳情况下达到 4Δ 延迟，与不支持动态参与的经典 BFT 协议相当。该协议还支持腐败节点参与度增长、诚实参与度任意波动，并为新活跃节点提供高效恢复机制。

Short Privacy-Preserving Proofs of Liabilities

Francesca Falzon, Kaoutar Elkhiyaoui, Yacov Manevich, Angelo De Caro

核心总结

在去中心化交易所欺诈丑闻和用户重大财务损失之后，监管机构需要机制来强制执行客户保护和资本要求。负债证明（Proof of Liabilities, PoL）允许证明方（如交易所）向验证方（如客户）证明其负债，是其中一种机制。本文提出短隐私保护负债证明，目标是在保持证明简洁的同时不泄露用户余额等敏感信息。摘要片段未给出具体构造和实验数据，但该工作聚焦于面向去中心化生态的隐私保护 PoL 方案。

Threshold Signatures from Inner Product Argument: Succinct, Weighted, and Multi-threshold

Sourav Das, Philippe Camacho, Zhuolun Xiang, Javier Nieto, Benedikt Bünz, Ling Ren

核心总结

门限签名通过在一组签名者之间共享签名密钥来保护密钥，但现有兼具简洁签名和常数验证时间的门限签名方案不支持签名者权重不同的场景，而这种加权设置在权益证明等去中心化系统中日益重要。本文提出一种面向配对和离散对数密码系统的新门限签名范式，支持任意权重分布和任意门限。该方案验证密钥仅 7 个群元素，签名仅 8 个群元素，验证需要 8 次指数运算和 8 次双线性配对；在通用 powers-of-tau 设置后仅需非交互式预处理。作者在代数群模型中证明安全性，并用 Golang 实现；评估显示其签名大小和验证时间与标准非加权门限签名相当，且公钥验证密钥远小于现有多签名方案。

How Hard is Takeover in DPoS Blockchains? Understanding the Security of Coin-based Voting Governance

Chao Li, Balaji Palanisamy, Runhua Xu, Li Duan, Jiqiang Liu, Wei Wang

核心总结

EOSIO、Steem 和 TRON 等委托权益证明（DPoS）区块链通过代币投票选举区块生产者委员会进行治理。Steem 与 TRON 之间发生的首次事实上的区块链接管事件，使 TRON 创始人在一小时内控制了整个 Steem 委员会，迫使原社区离开；但人们对 DPoS 链普遍易受接管攻击的程度及如何提升抵抗力仍知之甚少。本文旨在理解基于代币投票治理的 DPoS 区块链接管难度，分析其脆弱性并探索改进抵抗力的方法。该工作以真实接管事件为动机，聚焦 DPoS 治理安全，但摘要未展开具体分析框架与实验结果。

Uncle Maker: (Time)Stamping Out The Competition in Ethereum

Aviv Yaish, Gilad Stern, Aviv Zohar

核心总结

论文揭示并分析了针对以太坊1共识机制的一种新型攻击“Uncle Maker”，矿工通过操纵区块时间戳和难度调整算法，在区块竞争中获得比诚实矿工更高的挖矿收益。该攻击会提高叔块（uncle block）率，并包含多种变体，其中一种对矿工而言无风险。研究结果对以太坊共识安全与激励设计具有重要影响。

Faster Constant-time Evaluation of the Kronecker Symbol with Application to Elliptic Curve Hashing

Diego F. Aranha, Benjamin Salling Hvass, Bas Spitters, Mehdi Tibouchi

核心总结

论文将用于常数时间模逆的Bernstein-Yang算法推广到计算Kronecker符号（Jacobi和Legendre符号为其特例），并提出易于实现的全精度除法版本和基于字长输入的优化版本，且对优化版本进行了形式化验证。作者引入多项常数时间优化，特别适用于稠密素数下的Legendre符号计算，因为此时缺乏高效加法链。实验表明新算法比幂运算快达40倍，比此前最优方法快25.7%，并在SwiftEC椭圆曲线哈希和CTIDH等应用中取得显著加速。

Analyzing the Real-World Security of the Algorand Blockchain

Erica Blum, Derek Leung, Julian Loss, Jonathan Katz, Tal Rabin

核心总结

Algorand共识协议通过“玩家可替换性”实现自适应安全，每步由随机选出的秘密委员会执行，并在任意网络条件下提供一致性、在网络分区间歇时提供活性。论文对Algorand区块链在真实世界中的安全性进行系统分析，考察其理论假设与实际部署之间的差距及潜在攻击面。研究结果对保护当时价值约8.5亿美元的Algorand加密货币具有重要意义。

FutORAMa: A Concretely Efficient Hierarchical Oblivious RAM

Gilad Asharov, Ilan Komargodski, Yehuda Michelson

核心总结

该论文针对ORAM在隐藏内存访问模式时具体开销过高、难以实际部署的问题，提出FutORAMa一种具体高效的分层ORAM方案。现有最优实用ORAM方案仅适合较小内存，作者旨在突破这一限制。标题表明其采用分层结构并进行具体效率优化。该工作有望推动ORAM在安全计算等应用中的实际使用。

Accio: Variable-Amount, Optimized-Unlinkable and NIZK-Free Off-Chain Payments via Hubs

Zhonghui Ge, Jiayuan Gu, Chenke Wang, Yu Long, Xian Xu, Dawu Gu

核心总结

该论文针对支付通道枢纽中隐私保护方案的问题：支持可变金额但不可链接性有限、易受中止攻击，且依赖零知识证明造成高计算和通信开销。作者提出Accio，一种基于枢纽的链下支付方案，支持可变金额、优化不可链接性并免除NIZK。它通过减少高成本密码工具的使用来提升大规模实用性。摘要未给出具体性能数据，但目标是在保持隐私属性的同时降低成本。

Stealth Key Exchange and Confined Access to the Record Protocol Data in TLS 1.3

Marc Fischlin

核心总结

该论文研究在标准TLS 1.3执行中嵌入隐蔽密钥交换子协议，从而在正常会话密钥之外生成一个隐蔽密钥。其思路利用交换的nonce携带另一个密钥值。作者给出了此类嵌入密钥交换的严格安全模型与分析，要求即使常规密钥被攻击者控制，隐蔽密钥仍保持安全。针对TLS 1.3的隐蔽版本，论文证明在常规TLS假设下该额外密钥仍安全。

ParBFT: Faster Asynchronous BFT Consensus with a Parallel Optimistic Path

Xiaohai Dai, Bolin Zhang, Hai Jin, Ling Ren

核心总结

该论文关注异步拜占庭容错共识中乐观路径设计对网络延迟Δ估计敏感的问题。现有Ditto、BDT等协议先运行乐观路径，超时后切换悲观路径，若Δ估计错误会导致切换过早或过晚，损害效率。作者提出ParBFT，引入并行乐观路径来加快异步BFT共识。摘要未展开实验，但目标是在保证异步活性的同时提升好情况与切换情况下的性能。

Verifiable Mix-Nets and Distributed Decryption for Voting from Lattice-Based Assumptions

Diego F. Aranha, Carsten Baum, Kristian Gjøsteen, Tjerand Silde

核心总结

该论文研究基于格假设的后量子电子投票协议，聚焦混洗-解密范式中可验证混洗与分布式解密。现有实用投票协议多依赖离散对数型假设，其设计难以直接迁移到格设置，因为噪声增长和近似关系等问题。作者提出基于格的、可验证的混洗网络和分布式解密构造，以支持后量子安全的投票。摘要未给性能数据，但目标是在格假设下实现实用的投票隐私与可验证性。

HE3DB: An Efficient and Elastic Encrypted Database Via Arithmetic-And-Logic Fully Homomorphic Encryption

Song Bian, Zhou Zhang, Haowen Pan, Ran Mao, Zian Zhao, Yier Jin, Zhenyu Guan

核心总结

该论文针对全同态加密数据库面临高计算延迟和缺乏弹性查询处理的问题，提出HE3DB框架。它基于新的FHE基础设施，集成算术和逻辑同态算子，实现快速高精度同态比较与聚合，从而支持复合过滤-聚合、排序、分组和连接等SQL查询。与仅支持聚合信息检索的现有加密DBMS不同，HE3DB允许服务器端对查询后的密文进行弹性分析，如隐私决策树评估。实验表明，其端到端SQL查询比最优方案快41-299倍，在16位1万行数据库上完成TPC-H查询仅需241秒。

Securely Sampling Discrete Gaussian Noise for Multi-Party Differential Privacy

Chengkun Wei, Ruijing Yu, Yuan Fan, Wenzhi Chen, Tianhao Wang

核心总结

差分隐私通过限制从聚合数据中推断个体信息来保护隐私，近期研究利用安全多方计算（MPC）实现DP，以避免依赖可信第三方。噪声采样是在MPC中实现DP的关键组件之一。该论文提出首个用于采样离散高斯噪声的MPC解决方案，离散高斯是构造DP机制的常用噪声类型。该方案能与恶意安全MPC协议良好兼容，为多参与方DP提供安全噪声采样基础。

PELTA - Shielding Multiparty-FHE against Malicious Adversaries

Sylvain Chatel, Christian Mouchet, Ali Utkan Sahin, Apostolos Pyrgelis, Carmela Troncoso, Jean-Pierre Hubaux

核心总结

多参与方全同态加密（MFHE）允许多方在保持数据机密性的同时高效计算函数，但现有方案仅在诚实但好奇敌手模型下保证机密性和计算正确性。该论文提出首个实用构造，通过零知识证明验证MFHE操作，从而抵御恶意敌手。方案结合格基承诺方案和证明系统，并适配现代FHE方案及其实现优化。实验评估显示PELTA比现有技术快一到两个数量级。

Level Up: Private Non-Interactive Decision Tree Evaluation using Levelled Homomorphic Encryption

Rasoul Akhavan Mahdavi, Haoyan Ni, Dimitry Linkov, Florian Kerschbaum

核心总结

随着机器学习即服务普及，用户不愿向服务商泄露私有数据，服务商也希望保护模型知识产权，因此隐私保护推理变得重要。决策树因简单、可解释且易训练而被广泛使用。私有决策树评估（PDTE）允许服务器基于客户端私有属性提供预测，同时服务器学不到客户端属性，客户端除预测和部分超参数外学不到模型信息。论文利用分层同态加密提出一种非交互式PDTE协议。

A Generic Methodology for the Modular Verification of Security Protocol Implementations

Linard Arquint, Malte Schwerhoff, Vaibhav Mehta, Peter Müller

核心总结

安全协议是现代 IT 系统的关键组件，设计或实现中的细微缺陷可能危及整个系统，但已有工作多验证协议模型，或对实现验证施加严格的语言与代码设计限制。论文提出一种在协议实现层面进行模块化验证的方法，利用现代验证逻辑与工具支持多种实现和编程语言。作者用 Go 实现的 Needham-Schroeder-Lowe、Diffie-Hellman 密钥交换和 WireGuard 验证内存安全与安全性，包括 WireGuard 的前向保密和单射一致性，并用 C 原型表明方法不依赖特定语言或验证器。

AIM: Symmetric Primitive for Shorter Signatures with Stronger Security

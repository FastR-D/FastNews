PyLingual: Toward Perfect Decompilation of Evolving High-Level Languages

Joshua Wiedemeier, Elliot Tarbet, Max Zheng, Sangsoo Ko, Jessica Ouyang, Sang Kil Cha, Kangkook Jee

核心总结

Python 广泛用于开发和恶意软件，但 Python 反编译工具因语言和字节码规范快速演进而难以维护。本文提出 PyLingual，将 NLP 技术与传统编程语言理论结合，构建版本无关核心并插入数据驱动组件，自动吸收表层字节码和编译器变化，同时用程序化组件重建抽象控制流。为可信评估，作者提出“完美反编译”这一可静态验证的语义等价细化度量，并使用真实良性/恶意 Python 源码及 PYC 二进制进行实验。结果显示 PyLingual 支持 Python 3.6 至 3.12，在四个数据集上完美反编译率平均比现有最佳工具提升 45%，并作为公开在线服务发布。

GoSonar: Detecting Logical Vulnerabilities in Memory Safe Language Using Inductive Constraint Reasoning

Md Sakib Anwar, Carter Yagemann, Zhiqiang Lin

核心总结

随着内存安全语言推广，其非内存安全类逻辑漏洞成为关键威胁，尤其Go常用于资源敏感的云应用，易受非终止、资源耗尽漏洞影响。本文提出归纳约束推理方法，用于评估复杂真实程序中的非终止性，并在标准数据集上优于现有工具。方法采用二进制级欠约束符号执行，收集多次递归迭代所需约束，通过对约束求一阶导数对递归函数建模分类，判断子目标是否收敛到全局目标。该研究解决了Go程序分析中的多项挑战，并实际部署检测失控递归，在Go标准库中发现5个新漏洞。

You Can’t Judge a Binary by Its Header: Data-Code Separation for Non-Standard ARM Binaries using Pseudo Labels

Hadjer Benkraouda, Nirav Diwan, Gang Wang

核心总结

静态二进制分析对漏洞发现和恶意软件检测至关重要，但 IoT 与工业控制系统厂商不断引入现有工具无法处理的自定义或非标准二进制格式，逆向每种新格式成本高昂。论文研究非标准二进制自动化分析的第一步：区分代码字节与数据字节。作者提出 Loadstar，利用标准二进制的大量标注数据训练分类器，并通过基于伪标签的域自适应迁移到未标注的非标准二进制；同时使用知识启发式规则校正伪标签，作为自适应过程的护栏，且无需标注任何非标准二进制。在三个非标准 PLC 二进制数据集上，Loadstar 在准确率和处理速度上均优于现有工具，并将开源该工具。

FirmRCA: Towards Post-Fuzzing Analysis on ARM Embedded Firmware with Efficient Event-based Fault Localization

Boyu Chang, Binbin Zhao, Qiao Zhang, Peiyu Liu, Yuan Tian, Raheem Beyah, Shouling Ji

核心总结

尽管模糊测试能发现嵌入式固件漏洞，但发现崩溃用例只是第一步，后续自动化的根因定位仍研究不足，主要挑战包括调试机制不足、固件二进制导致可疑指令过度污染和噪声大。本文设计并实现了 FirmRCA，一个面向嵌入式固件的实用故障定位框架。FirmRCA 引入基于事件的足迹收集方法，利用崩溃复现过程中的具体内存访问来加速反向执行；并通过历史驱动的数据传播跟踪解决复杂内存别名问题，从而精确定位深层崩溃根源；最后用新策略高亮与根因相关的关键指令。在 17 个固件镜像的 41 个崩溃用例上，FirmRCA 在 top 10 指令内识别根因的成功率达 92.7%，相比现有工作在全执行轨迹分析能力上提升 27.8%，整体效率达多项式级加速，top 10 成功率提升 73.2%。

Inspecting Virtual Machine Diversification Inside Virtualization Obfuscation

Naiqian Zhang, Dongpeng Xu, Jiang Ming, Jun Xu, Qiaoyan Yu

核心总结

虚拟化混淆常被用于保护专有代码或阻碍恶意软件分析，其虚拟机（VM）采用多种多样化技术来复杂化内部结构，但此前缺乏对这些技术的系统研究。本文从 VM 解释、字节码组织以及 handler 置换/重定位等角度对 VM 多样化技术进行分类和揭示，并开发自动化工具识别最先进虚拟化混淆器采用了哪些多样化技术。作者还用这些新知识修补现有去混淆工具以克服其弱点，结果表明该研究揭示了 VM 多样化在实践中的部署方式，并为下一代 VM 去混淆铺平道路。

Disassembly as Weighted Interval Scheduling with Learned Weights

Antonio Flores-Montoya, Junghee Lim, Adam Seitz, Akshay Sood, Edward Raff, James Holt

核心总结

反汇编是逆向工程、二进制重写等多种二进制分析与变换技术的第一步；近期方法通常包括探索阶段、分析阶段和冲突解决阶段，其中分析阶段为候选指令或基本块赋权，冲突解决阶段确定最终指令集合。本文提出一种适用于x86、x64、arm32和aarch64的通用反汇编算法，其冲突解决方法将反汇编归约为加权区间调度，并提出权重分配算法以学习分析阶段各启发式的最优权重。实验表明，学习得到的权重在多数情况下优于人工调参，并通过将40%启发式的权重置零减少了所需启发式数量。基于Ddisasm的实现，在多项指标上优于现有最先进反汇编器，并在所有评估数据集上以明显优势实现了最高比例的完美反汇编二进制。

Redefining Indirect Call Analysis with KallGraph

Guoren Li, Manu Sridharan, Zhiyun Qian

核心总结

调用图构建是许多静态分析的基础，现有基于类型分析的方法虽可扩展至 Linux 内核等大型程序，但作者发现其可靠性存在新问题：部分声明的健全性不成立，导致遗漏间接调用目标，同时又在多方面过度保守，产生大量误报目标。基于这些观察，论文将类型分析方法转化为混合指针分析框架，统一传统指针跟踪与类型分析，并实现实用的间接调用分析工具 KallGraph。KallGraph 同时提升精度与健全性，可剪枝最多 90% 的间接调用目标，并消除数百到数千个遗漏的间接调用。该工具可完全并行化，分析 Linux 内核耗时从数十分钟到数小时。

CONnecting The EXtra doTS (CONTEXTS): Correlating External Information about Point of Interest for Attack Investigation

Sareh Mohammadi, Hugo Kermabon-Bobinnec, Azadeh Tabiban, Lingyu Wang, Tomás Navarro Múnera, Yosr Jarraya

核心总结

溯源分析是安全事件调查的重要方法，但溯源图规模巨大，现有剪枝方案通常只把事件当作抽象起点，未利用事件相关的外部信息，从而错过剪枝机会。论文提出 Contexts，通过提取漏洞或利用方式等外部上下文信息，将其映射到溯源图节点，并关联这些节点形成与事件相关的子图，以补充现有剪枝方法。在真实攻击上的实验表明，作为现有剪枝方法的预处理器，它可将误报从超过 150k 降至不足十个；作为独立剪枝方案，它在 20 个攻击中的 19 个达到 100% TPR，并在 16 个攻击中 FPR 低于 0.6%。用户研究中 94.4% 的参与者认可其在攻击调查中的实用性，展示了现实可行性。

TypeForge: Synthesizing and Selecting Best-Fit Composite Data Types for Stripped Binaries

Yanzhong Wang, Ruigang Liang, Yilin Li, Peiwei Hu, Kai Chen, Bolun Zhang

核心总结

剥离二进制文件缺乏类型信息，尤其是复合数据类型，严重阻碍静态分析和逆向工程，现有方法在准确性和可扩展性上存在不足。本文提出 TypeForge，受逆向工程专家工作流启发，采用两阶段合成-选择策略自动恢复复合数据类型。作者设计类型流图（TFG）表示二进制中的类型信息；第一阶段基于 TFG 高效构建约束并合成可能的复合类型声明，第二阶段提出 LLM 辅助的双重淘汰框架，通过评估反编译代码可读性选择最佳类型声明。实验表明，TypeForge 在复合数据类型识别和布局恢复上 F1 分别达 81.7% 和 88.2%，关系恢复 F1 为 72.1%，且时间开销仅为最佳现有方法 OSPREY 的约 3.8%。

Empc: Effective Path Prioritization for Symbolic Execution with Path Cover

Shuangjie Yao, Dongdong She

核心总结

符号执行能系统探索程序路径并发现漏洞，但路径爆炸严重限制其可扩展性。现有路径优先策略多依赖静态规则或启发式排序，难以泛化到多样程序。本文提出Empc，核心思想是并非所有路径都需要符号推理，而是用能覆盖被测程序所有代码区域的最小子集（最小路径覆盖MPC）来指导搜索，并计算多个MPC以增加路径多样性。基于KLEE实现后，Empc比KLEE最佳搜索策略多覆盖19.6%基本块、比cgs多24.4%代码行，多发现24个安全违规，同时将KLEE内存占用最多降低93.5%、符号状态数最多降低88.6%。

Verifiable Secret Sharing Simplified

Sourav Das, Zhuolun Xiang, Alin Tomescu, Alexander Spiegelman, Benny Pinkas, Ling Ren

核心总结

可验证秘密共享（VSS）是密码学基础组件，但现有协议复杂低效，常不支持双阈值、公开可验证或异步安全终止。本文提出一套同步和异步网络下设计 VSS 的简洁新方法，分别容忍 1/2 和 1/3 恶意节点，仅需公钥基础设施和离散对数困难性。协议支持双阈值且记录可公开验证。实现并在最多 256 节点的地理分布式环境中评估，展示异步终止和公开可验证性，同时带宽和延迟相比同类方案最多降低 90%。

Volatile and Persistent Memory for zkSNARKs via Algebraic Interactive Proofs

Alex Ozdemir, Evan Laufer, Dan Boneh

核心总结

可验证外包中，不受信服务器运行昂贵计算并生成简洁SNARK证明；许多场景中计算会访问服务器承诺的持久RAM或初始为零的易失RAM，但现有RAM检查技术开销高。本文为易失、持久和稀疏持久RAM开发新的证明，降低SNARK证明时间，包括持久RAM最高51.3倍具体提升。方法上，将任意代数交互证明（AIP）转换为SNARK的构造进行推广，并利用多项式Bézout恒等式构造新的AIP，用于证明唯一性和不相交性，从而证明对不同地址访问的独立性。这些工具可能具有独立价值。

Zero-Knowledge Location Privacy via Accurate Floating-Point SNARKs

Jens Ernstberger, Chengru Zhang, Luca Ciprian, Philipp Jovanovic, Sebastian Steinhorst

核心总结

本文提出零知识位置隐私（ZKLP），让用户能向第三方证明自己位于指定地理区域而不泄露精确位置，并支持不同粒度。为实现ZKLP，作者提出首套完全符合IEEE 754浮点算术标准的零知识证明电路。结果显示浮点电路可高效摊销，单精度浮点乘法每次仅需64个约束。与基线相比，单精度浮点实现约束减少15.9倍，双精度减少12.2倍。作者构建隐私保护点对点邻近测试协议，Bob可在0.26秒内生成（非）邻近证明，Alice每秒可验证约470个同伴的距离，双方不泄露其他位置信息。

RankGuess: Password Guessing Using Adversarial Ranking

Tao Yang, Ding Wang

核心总结

理解密码猜测攻击是评估密码安全性的关键，攻击者通常按可能性降序猜测，类似于推荐系统中的生成式检索排序。论文提出基于对抗排序的密码猜测框架 RankGuess，将密码创建过程视为序列决策轨迹，把猜测问题建模为马尔可夫决策过程，并用排序器给出的评分作为奖励信号。该框架具有通用性，可适用于拖网猜测、基于个人身份信息（PII）的目标猜测和条件密码猜测。在 12 个大规模密码数据集和 6 个 PII 数据集上，RankGuess 超过所有当前最优模型，比基于 GAN 的方法提升 26.29%~43.69%（平均 34.80%）。在 PII 目标和部分密码条件下，RankGuess-PII 与 RankGuess-Mask 也分别比最强基线提升 6.32%~17.09% 和平均 8.21%。

TreePIR: Efficient Private Retrieval of Merkle Proofs via Tree Colorings with Fast Indexing and Zero Storage Overhead

Quang Cao, Son Hoang Dau, Rinaldo Gagiano, Duy Huynh, Xun Yi, Phuc Lu Le, Quang-Hung Luu, Emanuele Viterbo, Yu-Chih Huang, Jingge Zhu, Mohammad M. Jalalza, Chen Feng

核心总结

批量私有信息检索（batch-PIR）允许客户端在不向存储服务器泄露查询内容的情况下取回多个数据项，但现有基于概率批量码（PBC）的方案存储开销很大。论文针对树形数据库提出 TreePIR，实现零存储冗余地私有检索 Merkle 树中任意根到叶路径上的节点集合（即 Merkle 证明）。该方法采用新颖的树着色，适用于 Amazon DynamoDB、Google 证书透明度和区块链等广泛使用 Merkle 树的系统。与最先进批量 PIR 方案中的 PBC 相比，TreePIR 总存储降低 3 倍，计算和通信开销降低 1.5~3 倍，setup 时间降低 8~160 倍。对于 2^10 至 2^24 个叶子的树，其 polylog 复杂度索引算法比 PBC 快 19~160 倍。

Benchmarking Attacks on Learning with Errors

Emily Wenger, Eshika Saxena, Mohamed Malhou, Ellie Thieu, Kristin Lauter

核心总结

基于学习带误差（LWE）的格密码已被 NIST 和 HomomorphicEncryption.org 标准化，因此理解其具体安全性至关重要；然而现有研究多关注理论攻击估计，唯一的基准测试 Darmstadt Lattice Challenge 又不覆盖标准化 LWE 参数（如小秘密、小误差、Ring-LWE 和 Module-LWE）。本文首次针对标准化参数下的小秘密和低重量稀疏秘密恢复提供基准测试。作者评估四种 LWE 攻击：搜索型 uSVP、SALSA、Cool&Cruel，以及判定型 Dual Hybrid Meet-in-the-Middle，并对 SALSA 和 Cool&Cruel 做了显著扩展，首次实现并扩展 MitM 攻击。实验表明，SALSA 和 Cool&Cruel 可在 28–36 小时内恢复 Kyber（κ=2）参数下汉明重量 9–11 的二项秘密；MitM 可在不到一小时内解决 Kyber 参数下汉明重量至多 4 的判定型 LWE 实例；而 uSVP 运行超过 1100 小时仍未恢复任何秘密。作者还比较了实际性能与理论估计，并开源代码以促进后续研究。

Phecda: Post-Quantum Transparent zkSNARKs from Improved Polynomial Commitment and VOLE-in-the-Head with Application in Publicly Verifiable AES

Changchang Ding, Yan Huang

核心总结

本文面向抗量子和透明 zkSNARK 需求，提出新框架 Phecda，用于在随机预言机模型中构造可验证真实世界计算的零知识证明。Phecda 包含一种新的多线性多项式承诺方案和一种新的 VOLE-in-the-Head 零知识论证，并设计了一种新颖的 AES 验证电路。结合这些技术，Phecda 可在 Linux PC 上以单线程程序在约 10 毫秒内验证 1024 个计数模式 AES 块。该工作为后量子透明零知识证明在实际计算验证中的应用提供了高效方案。

VerITAS: Verifying Image Transformations at Scale

Trisha Datta, Binyi Chen, Dan Boneh

核心总结

图像来源验证对新闻媒体等场景很重要，C2PA 标准依赖相机对原始照片签名，但照片通常经过编辑，仅有编辑后图像时无法直接验证原始签名。本文提出 VerITAS，使用 zk-SNARK 证明一张已签名照片只经历了特定编辑，并且首次支持高达 3000 万像素的真实大图。其关键创新是设计了一种新证明系统，能够证明对大量 witness 数据上有效签名的知识。实验表明，对 90 MB 图像，弱签名者约 13 分钟、AWS 成本约 0.54 美元，强签名者约 3 分钟、成本约 0.13 美元，而证明验证时间不到一秒。

Sailfish: Towards Improving the Latency of DAG-based BFT

Nibesh Shrestha, Rohan Shrothrium, Aniket Kate, Kartik Nayak

核心总结

基于 DAG 的 BFT 协议能平衡共识负载并保持高吞吐，但现有协议提交延迟较长，主要因为 leader 只出现在每两个或更多轮中，近期工作甚至认为每轮支持 leader 顶点非常困难。本文提出 Sailfish，首个在每一轮都支持 leader 顶点的 DAG-based BFT 协议。在诚实 leader 情况下，Sailfish 提交 leader 顶点仅需一个可靠广播轮加 δ，提交非 leader 顶点额外只需一个可靠广播轮，并进一步扩展为 Multi-leader Sailfish 以支持单轮多个 leader。实验显示，与现有 DAG 协议相比，Sailfish 在保持相似吞吐的同时显著降低延迟开销。

Ringtail: Practical Two-Round Threshold Signatures from Learning with Errors

Cecilia Boschini, Darya Kaviani, Russell W. F. Lai, Giulio Malavolta, Akira Takahashi, Mehdi Tibouchi

核心总结

门限签名将签名密钥分给多方，任意 t 方子集可联合签名，而设计具体高效的后量子门限签名是 NIST 近期呼吁的重要问题。本文提出、实现并评估了基于格的 Ringtail，首次同时实现两轮签名、第一轮消息无关可离线预处理、可扩展到 t 不超过 1024 方，并基于标准 LWE 假设在随机预言机模型下安全。对于 128 位安全和 t=1024，签名大小为 13.4 KB，在线通信为 10.5 KB。作者还进行了首次横跨 8 个国家、5 个大洲的 WAN 部署实验，发现端到端延迟绝大部分来自网络延迟，说明轮数优化尤为关键。

CHLOE: Loop Transformation over Fully Homomorphic Encryption via Multi-Level Vectorization and Control-Path Reduction

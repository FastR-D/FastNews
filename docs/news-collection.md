# 研究资讯采集

信源配置位于服务器语料目录 `config/news-sources.json`；仓库同名文件提供核验后的部署配置。论文、资讯与账号状态不随代码提交。

管理员在信源目录右上角切换「纳入采集 / 移除采集」：启用后纳入后续定时采集并立即排队，停用会移除待执行条目，已经发出的请求可以完成，历史数据保留。进程管理展示任务、各来源结果、读取/过期/新增数和实际使用的直连/新加坡网络路线。

`internal/catalog/news_source_presets.json` 是已核验接口注册表，不会自动订阅。目录中已提供适配器的来源可直接启用；需要第三方账号或尚无稳定接口的来源进入待接入队列。候选不会被伪装成已成功采集。

支持 RSS / Atom / RDF、CISA KEV JSON、NVD 2.0 recent gzip 数据。NVD 只收录 HIGH/CRITICAL 评级记录，保留 CVE、原始描述与官方链接；评级不等于在野利用。CISA 单独保留在野利用事实。OSV 接入团队博客，不宣称同步了全量漏洞数据库。

每条信源可设置 `transport: direct | relay | auto`，以及 `max_age_days`。默认 14 天；深度研究来源可设 90/365 天，`-1` 为显式回填。NVD 解压后限制 64 MiB，普通信源 16 MiB。自动换路不重试 401/403/429；不会解决验证码、付费墙或登录授权限制。公开源名称与订阅元数据可展示，凭据不进入目录 API。

账号/跳板机部署见 [部署文档](fastdeploy.md)，逐项核验与删除记录见 [本次信源核验](source-audit-2026-11-27.md)。

# 账号与管理员

公开自主注册已关闭。本地账号由管理员创建，或在首次 FastCAS 登录后填写姓名、邮箱及本地密码，再经 FastCAS 确认创建并绑定。已有邮箱应使用原账号登录后绑定。

FastCAS 的已验证 `profile.role=admin` 会在登录或绑定成功时将对应平台账号提升为管理员。FastCAS 普通用户登录保留平台已有角色。停用账号无法登录。

管理员从「用户管理」搜索、创建、修改和删除账号，可修改邮箱、姓名、角色、启用状态并重置密码。修改凭据、角色或状态会撤销已有会话。删除账号保留其内容并停止登录。当前管理员和最后一名启用的管理员受到保护，管理操作记录原因。

接口：`GET/POST /api/admin/users`、`PATCH/DELETE /api/admin/users/{id}`。写入沿用本地会话的 CSRF 校验。

CAS 注册接口为 `GET/POST /api/auth/fastcas/registration`。注册状态与浏览器绑定，五分钟有效；两次回调必须对应同一 FastCAS 身份。账号与待激活绑定在同一事务中保存，激活中断可在下一次 CAS 登录时恢复。
